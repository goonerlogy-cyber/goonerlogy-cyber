Developer tools, terminal interfaces, and systems that behave predictably when something fails.

review in my forks; they are not upstream releases. Original authorship and licenses
remain credited in each repository.

## What I care about

Small tools with a clear purpose. Failure cases you can reproduce. Documentation
that gets you from a clean checkout to a working example.

The best place to see the work is in the diffs and their regression tests.
